### 2. Custom Bezier Curve Easing ✅
**Task**: 1.5B.13 Create custom Bezier curve easing
**File**: `src/SkiaCharts.Core/Animation/EasingFunctions.cs`

#### Implementation Details
- Added `CreateBezier(x1, y1, x2, y2)` factory method
- Implemented `BezierEasing` class using binary search algorithm
- Supports CSS cubic-bezier() compatible curves
- Control points X coordinates are clamped to 0-1 range

#### Key Features
```csharp
// Factory method
public static IEasingFunction CreateBezier(double x1, double y1, double x2, double y2)

// CSS presets
var ease = CreateBezier(0.25, 0.1, 0.25, 1.0);         // CSS ease
var easeIn = CreateBezier(0.42, 0, 1.0, 1.0);          // CSS ease-in
var easeOut = CreateBezier(0, 0, 0.58, 1.0);           // CSS ease-out
var easeInOut = CreateBezier(0.42, 0, 0.58, 1.0);      // CSS ease-in-out
```

#### Algorithm
- Uses binary search to find t value for given x (10 iterations, 0.001 precision)
- Calculates cubic Bezier: `B(t) = 3(1-t)²t·P1 + 3(1-t)t²·P2 + t³`
- More stable than Newton-Raphson method
- Handles edge cases (t=0, t=1) directly

#### Use Cases
- Custom animation curves matching CSS animations
- Design-specific easing functions
- Prototyping and fine-tuning animation feel
- Cross-platform animation consistency (web/native)

## Technical Highlights

### ClipRegion Design Decisions

1. **Struct vs Class**: Chose `readonly struct` for:
   - Value semantics (no heap allocations)
   - Immutability (thread-safe, predictable)
   - Cache-friendly (better locality)

2. **Edge Properties**: Provides Left, Right, Top, Bottom as computed properties for convenience

3. **Intersection Algorithm**: Uses standard axis-aligned bounding box (AABB) intersection test - efficient O(1) operation

4. **Expand Method**: Useful for tolerance-based hit testing and margin calculations

### Bezier Easing Design Decisions

1. **Binary Search**: Chose binary search over Newton-Raphson for:
   - Simpler implementation
   - More stable convergence
   - Predictable performance (always 10 iterations)

2. **Control Point Clamping**: X coordinates must be 0-1 for monotonic function (required for easing)

3. **Precision**: 0.001 precision is sufficient for 60fps animations (1000 possible values)

4. **CSS Compatibility**: Matches CSS cubic-bezier() specification exactly
