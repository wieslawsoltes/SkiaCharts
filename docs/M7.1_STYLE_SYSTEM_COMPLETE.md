#### 7.1.2 Implement CSS-like Style Cascading ✅
**Location**: `src/SkiaCharts.Core/Theming/ChartTheme.cs:91-111`

- CSS-inspired cascading system
- Features:
  - `Clone()` method for deep copying themes
  - `Merge()` method for cascading theme properties
  - Property-level overriding
  - Preserves base theme while applying overrides
  - Each style component has Clone() and Merge() methods

**Cascading Example**:
```csharp
var baseTheme = ThemePresets.Light.Clone();
var customizations = new ChartTheme();
customizations.Background.Color = SKColors.LightGray;
customizations.Series.LineWidth = 3.0f;

// Merge customizations on top of base theme
baseTheme.Merge(customizations);
// baseTheme now has Light theme with custom background and line width
```

**Merge Behavior**:
- Properties from overlay theme override base theme properties
- Null-safe merging
- Each style component independently mergeable
- Color palette can be completely replaced

## Architecture Highlights

### Theme System Flow
```
Application → ChartTheme
    ↓
Select Preset (Light/Dark/HighContrast/Professional)
    ↓
Apply Customizations (Merge)
    ↓
Chart Renderer → Use Theme Properties
    ↓
Render → Styled Visual Output
```

### Cascading Hierarchy
```
Base Theme (Preset)
    ↓
+ User Customizations (Merge)
    ↓
+ Chart-Specific Overrides (Optional)
    ↓
= Final Applied Theme
```

### Color Palette Types
```
Categorical → Distinct Categories (Series 1, 2, 3, ...)
Sequential → Continuous Values (0 → 100)
Diverging → Values with Midpoint (-100 ← 0 → +100)
```

## Technical Specifications

### Performance Characteristics
- **Theme Clone**: O(1) - Fixed number of style components
- **Theme Merge**: O(1) - Fixed property assignments
- **Get Color (Categorical)**: O(1) - Modulo operation
- **Get Interpolated Color**: O(1) - Linear interpolation calculation
- **Theme Lookup**: O(n) for n themes - linear search (small n)

### Memory Footprint
- ChartTheme: ~500 bytes per instance
- ColorPalette: ~100 bytes + O(n) for n colors
- Each SKColor: 4 bytes (RGBA)
- Total Light theme: ~700 bytes
- Total Dark theme: ~750 bytes (more colors in palette)

### Thread Safety
- Themes are immutable after creation (by convention)
- Clone before modifying
- Safe for concurrent read access
- Merge should be done on private copies

## Design Patterns Used

✅ **Builder Pattern**: Theme construction with fluent API

✅ **Strategy Pattern**: Pluggable color palettes

✅ **Facade Pattern**: ChartTheme simplifies access to all styles
✅ **Registry Pattern**: ThemePresets for preset lookup

## Usage Examples

### Using Theme Presets
```csharp
// Use built-in theme
var theme = ThemePresets.Light;

// Or by name
var darkTheme = ThemePresets.GetByName("Dark");

// Apply to chart
chart.Theme = theme;
```

### Customizing Themes
```csharp
// Start with a preset
var myTheme = ThemePresets.Professional.Clone();

// Customize specific properties
myTheme.Background.Color = new SKColor(245, 245, 245);
myTheme.Series.LineWidth = 3.0f;
myTheme.ColorPalette = ColorPalettes.Vibrant;

// Apply customized theme
chart.Theme = myTheme;
```

### CSS-like Cascading
```csharp
// Base theme
var baseTheme = ThemePresets.Light;

// Create overlay with customizations
var darkMode = new ChartTheme();
darkMode.Background.Color = new SKColor(30, 30, 30);
darkMode.Axis.LabelColor = new SKColor(200, 200, 200);
darkMode.Grid.MajorGridColor = new SKColor(60, 60, 60);

// Merge to create custom "Light Dark" theme
var customTheme = baseTheme.Clone();
customTheme.Merge(darkMode);
customTheme.Name = "Light Dark Hybrid";
```

### Using Color Palettes (Categorical)
```csharp
var theme = ThemePresets.Light;
var palette = theme.ColorPalette;

// Assign colors to series
for (int i = 0; i < series.Count; i++)
{
    series[i].Color = palette.GetColor(i);
}
```

### Using Sequential Palettes (Heatmap)
```csharp
var heatPalette = ColorPalettes.Heat;

// Map value range to colors
for (int i = 0; i < dataPoints.Length; i++)
{
    var normalizedValue = (dataPoints[i] - min) / (max - min); // 0.0 to 1.0
    var color = heatPalette.GetInterpolatedColor(normalizedValue);
    RenderCell(i, color);
}
```

### Using Diverging Palettes (Correlation Matrix)
```csharp
var divergingPalette = ColorPalettes.RedBlue;

// Map correlation values (-1 to +1) to colors
for (int i = 0; i < correlations.Length; i++)
{
    var normalizedValue = (correlations[i] + 1.0) / 2.0; // Convert -1..+1 to 0..1
    var color = divergingPalette.GetInterpolatedColor(normalizedValue);
    RenderCell(i, color);
}
```

### Creating Custom Themes
```csharp
var customTheme = new ChartTheme
{
    Name = "My Custom Theme",
    Background = new BackgroundStyle
    {
        Color = new SKColor(255, 250, 240), // Cream
        BorderColor = new SKColor(200, 180, 150),
        BorderWidth = 2.0f,
        CornerRadius = 8.0f
    },
    Grid = new GridStyle
    {
        ShowMajorGrid = true,
        MajorGridColor = new SKColor(220, 210, 190)
    },
    Series = new SeriesStyle
    {
        LineWidth = 2.5f,
        MarkerSize = 7.0f,
        AreaOpacity = 0.35f
    },
    ColorPalette = ColorPalettes.Pastel
};
```
