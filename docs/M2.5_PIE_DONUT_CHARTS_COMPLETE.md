## Technical Implementation Details

### Unified Pie/Donut Design

The `PieChart` class handles both pie and donut charts using a single implementation:

```csharp
public class PieChartConfiguration
{
    public bool IsDonut { get; set; } = false;
    public double InnerRadiusRatio { get; set; } = 0.5;
    // ... other properties
}
```

When `IsDonut` is `true`, the chart renders as a donut with the inner radius calculated as:
```csharp
var innerRadius = config.IsDonut
    ? (float)(outerRadius * config.InnerRadiusRatio)
    : 0f;
```

### Slice Rendering Algorithm

**For Pie Slices (innerRadius = 0):**
```csharp
path.MoveTo(center);
path.AddArc(rect, startAngle, sweepAngle);
path.Close();
```

**For Donut Slices (innerRadius > 0):**
```csharp
// Outer arc
path.AddArc(outerRect, startAngle, sweepAngle);
// Connect to inner arc
path.LineTo(innerPoint);
// Inner arc (reversed)
path.AddArc(innerRect, endAngle, -sweepAngle);
path.Close();
```

### Exploded Slice Positioning

Exploded slices are offset from the center along the slice's middle angle:

```csharp
var sliceCenterAngle = currentAngle + sweepAngle / 2f;
var sliceCenterRad = sliceCenterAngle * (float)Math.PI / 180f;
var explodeOffsetX = (float)Math.Cos(sliceCenterRad) * style.ExplodeDistance;
var explodeOffsetY = (float)Math.Sin(sliceCenterRad) * style.ExplodeDistance;

var sliceRect = new SKRect(
    centerX - outerRadius + explodeOffsetX,
    centerY - outerRadius + explodeOffsetY,
    centerX + outerRadius + explodeOffsetX,
    centerY + outerRadius + explodeOffsetY
);
```

### Percentage Calculation

```csharp
// Calculate total from positive values only
double totalValue = 0;
foreach (var point in series)
{
    if (point.Y > 0)
        totalValue += point.Y;
}

// Calculate sweep angle for each slice
var percentage = point.Y / totalValue;
var sweepAngle = (float)(percentage * 360);
```

### Label Positioning

**Inside Labels:**
```csharp
var labelRadius = config.IsDonut
    ? innerRadius + (outerRadius - innerRadius) / 2f  // Middle of ring
    : outerRadius * 0.6f;                             // 60% from center

var labelX = centerX + (float)Math.Cos(midRad) * labelRadius + explodeOffsetX;
var labelY = centerY + (float)Math.Sin(midRad) * labelRadius + explodeOffsetY;
```

**Outside Labels with Leader Lines:**
```csharp
var innerPoint = center + direction * outerRadius;
var outerPoint = center + direction * (outerRadius + leaderLineLength);

// Draw leader line
context.DrawLine(innerPoint, outerPoint);

// Adjust text alignment based on angle
if (normalizedAngle > 90 && normalizedAngle < 270)
    textPaint.TextAlign = SKTextAlign.Right;  // Left side of chart
else
    textPaint.TextAlign = SKTextAlign.Left;   // Right side of chart

context.DrawText(labelText, outerPoint);
```

### Label Formatting

```csharp
private string FormatLabel(PieLabelContent content, double value,
    double percentage, string? label, PieChartConfiguration config)
{
    return content switch
    {
        PieLabelContent.Percentage =>
            percentage.ToString(config.PercentageFormat),
        PieLabelContent.Value =>
            value.ToString(config.ValueFormat),
        PieLabelContent.Both =>
            $"{value.ToString(config.ValueFormat)} ({percentage.ToString(config.PercentageFormat)})",
        PieLabelContent.Name =>
            label ?? "",
        PieLabelContent.NameAndPercentage =>
            string.IsNullOrEmpty(label)
                ? percentage.ToString(config.PercentageFormat)
                : $"{label}\n{percentage.ToString(config.PercentageFormat)}",
        PieLabelContent.NameAndValue =>
            string.IsNullOrEmpty(label)
                ? value.ToString(config.ValueFormat)
                : $"{label}\n{value.ToString(config.ValueFormat)}",
        _ => ""
    };
}
```

### Radial Gradient Implementation

```csharp
if (style.GradientColors != null && style.GradientColors.Length > 0)

```

## Usage Example

### Basic Pie Chart

```csharp
var chart = new PieChart();

var series = new DataSeries<IDataPoint>(new IDataPoint[]
{
    new PieDataPoint(30, "Q1"),
    new PieDataPoint(50, "Q2"),
    new PieDataPoint(20, "Q3")
});

chart.Series.Add(series);
chart.Render(canvas, width, height);
```

### Donut Chart with Exploded Slice

```csharp
var chart = new PieChart();
chart.Configuration.IsDonut = true;
chart.Configuration.InnerRadiusRatio = 0.6;
chart.Configuration.LabelPosition = PieLabelPosition.Outside;
chart.Configuration.LabelContent = PieLabelContent.NameAndPercentage;

var series = new DataSeries<IDataPoint>(new IDataPoint[]
{
    new PieDataPoint(25, "Product A"),
    new PieDataPoint(35, "Product B"),
    new PieDataPoint(40, "Product C")
});

chart.Series.Add(series);

// Explode the second slice
chart.SetSliceStyle(series, 1, new PieSliceStyle
{
    FillColor = SKColors.Green,
    ExplodeDistance = 20f,
    BorderColor = SKColors.White,
    BorderWidth = 2f
});

chart.Render(canvas, width, height);
```

### Gradient Pie with Custom Colors

```csharp
var chart = new PieChart();
chart.Configuration.StartAngle = 90f; // Start from top
chart.Configuration.LabelPosition = PieLabelPosition.Inside;

var series = new DataSeries<IDataPoint>(new IDataPoint[]
{
    new PieDataPoint(40, "Revenue"),
    new PieDataPoint(60, "Costs")
});

chart.Series.Add(series);

chart.SetSliceStyle(series, 0, new PieSliceStyle
{
    GradientColors = new[] { SKColors.LightBlue, SKColors.DarkBlue }
});

chart.SetSliceStyle(series, 1, new PieSliceStyle
{
    GradientColors = new[] { SKColors.LightPink, SKColors.DarkRed }
});

chart.Render(canvas, width, height);
```
