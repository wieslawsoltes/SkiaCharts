### 3. ViewModel Binding Architecture ✅
**File:** `src/SkiaCharts.Avalonia/ViewModels/ChartViewModelBase.cs` (323 lines)

Implemented complete MVVM support with `INotifyPropertyChanged`:

**Base Class:**
```csharp
public abstract class ChartViewModelBase : INotifyPropertyChanged
{
    protected bool SetProperty<T>(ref T field, T value,
        [CallerMemberName] string? propertyName = null)
    {
        if (EqualityComparer<T>.Default.Equals(field, value))
            return false;
        field = value;
        OnPropertyChanged(propertyName);
        return true;
    }
}
```

## Issues Resolved

### 1. Generic Type Arguments
**Issue:** DataSeries requires generic type parameter
**Fix:** Changed from `DataSeries` to `DataSeries<DataPoint>` throughout

### 2. Immutable DataSeries
**Issue:** No `AddPoint()` method on DataSeries
**Fix:** Pass points to constructor: `new DataSeries<DataPoint>(points, name)`

### 3. Avalonia Property Naming Conflict
**Issue:** `Theme` property conflicts with Avalonia's built-in `Theme`
**Fix:** Renamed to `ChartTheme` property

### 4. Partial Class Declaration
**Issue:** Missing `partial` modifier for split class definition
**Fix:** Added `partial` keyword to `SkiaChartView` class

1. **Immutable DataSeries** - Efficient bounds caching
2. **Lazy Bounds Calculation** - Only when accessed

## Usage Example

```csharp
// In XAML
<charts:SkiaChartView
    Title="Sales Data"
    Subtitle="Q1 2025"
    Series="{Binding ChartSeries}"
    ShowLegend="True"
    LegendPosition="Right"
    ShowGrid="True"
    EnableAnimations="True"
    AnimationDuration="0:0:0.5"
    LineWidth="2"
    MarkerSize="6"
    ShowMarkers="True" />

// In ViewModel
public class MainViewModel : ChartViewModelBase
{
    public MainViewModel()
    {
        AddSeries("Product A", new[]
        {
            new DataPoint(1, 100),
            new DataPoint(2, 150),
            new DataPoint(3, 120)
        });
    }
}
```
