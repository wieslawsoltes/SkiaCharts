## Architecture

### View Model Pattern

All view models follow consistent patterns:

**Linear Axis Pattern:**
```csharp
public class LinearAxisViewModel : ReactiveObject
{
    public LinearAxisViewModel()
    {
        Chart = new LineChart { /* config */ };

        var points = new List<IDataPoint>();
        for (int i = 0; i <= 20; i++)
        {
            double x = i;
            double y = 2 * x + 10;  // Linear function
            points.Add(new DataPoint(x, y));
        }

        var series = new DataSeries<IDataPoint>(points, "Linear Function");
        Chart.Series.Add(series);
    }

    public LineChart Chart { get; }
}
```

**Logarithmic Scale Pattern:**
```csharp
// Exponential data benefits from log scale
for (int i = 0; i <= 10; i++)
{
    double x = i;
    double y = Math.Pow(10, i * 0.5);  // Exponential growth
    points.Add(new DataPoint(x, y));
}
```

**DateTime Pattern:**
```csharp
var baseTime = new DateTime(2025, 1, 1, 0, 0, 0);
for (int hour = 0; hour < 24; hour++)
{
    var time = baseTime.AddHours(hour);
    double temp = 15 + 8 * Math.Sin((hour - 6) * Math.PI / 12) + noise;
    points.Add(new DataPoint(time.ToOADate(), temp));
}
```

**Category Pattern:**
```csharp
// Discrete categories with numeric X values
var points = new List<IDataPoint>
{
    new DataPoint(1, 145),  // Category 1
    new DataPoint(2, 98),   // Category 2
    // ...
};
```
