```csharp
_allSeries = new List<IDataSeries<IDataPoint>>
{
    CreateSeries("Revenue", new SKColor(33, 150, 243), 0),
    CreateSeries("Expenses", new SKColor(244, 67, 54), 0.5),
    CreateSeries("Profit", new SKColor(76, 175, 80), 1.0)
};
```

**Visibility Toggle Pattern:**
```csharp
public bool Series1Visible
{
    get => _series1Visible;
    set
    {
        this.RaiseAndSetIfChanged(ref _series1Visible, value);
        UpdateVisibleSeries();
    }
}

private void UpdateVisibleSeries()
{
    Chart.Series.Clear();

    if (Series1Visible)
        Chart.Series.Add(_allSeries[0]);

    if (Series2Visible)
        Chart.Series.Add(_allSeries[1]);

    if (Series3Visible)
        Chart.Series.Add(_allSeries[2]);

    this.RaisePropertyChanged(nameof(Chart));
}
```

**Interactive Controls:**
```xml
<StackPanel Orientation="Horizontal" Spacing="24">
    <CheckBox IsChecked="{Binding Series1Visible}" Content="Revenue" />
    <CheckBox IsChecked="{Binding Series2Visible}" Content="Expenses" />
    <CheckBox IsChecked="{Binding Series3Visible}" Content="Profit" />
</StackPanel>
```

```csharp
    // Interaction methods for future event wiring
```

## Error Resolution

### Error: AreaChart Property Configuration

**Initial Error:**
```
error CS0117: 'AreaChart' does not contain a definition for 'LineWidth'
error CS0117: 'AreaChart' does not contain a definition for 'ShowMarkers'
error CS0117: 'AreaChart' does not contain a definition for 'MarkerSize'
```

**Cause:** Initially used LineChart-style properties on AreaChart

**Fix:** Changed to use AreaChart's Configuration and DefaultStyle pattern:
```csharp
// Before:
Chart = new AreaChart
{

    MarkerSize = 7f
};

{
    Configuration = new AreaChartConfiguration

    }
};
```
