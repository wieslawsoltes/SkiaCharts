## Architecture

### View Model Pattern

All view models follow a consistent pattern:

```csharp
public class XyzViewModel : ReactiveObject
{
    public XyzViewModel()
    {
        // Create chart instance
        Chart = new XyzChart
        {
            Configuration = new XyzConfiguration { ... },
            DefaultStyle = new XyzStyle { ... }
        };

        // Create sample data
        var points = new List<DataPoint> { ... };
        var series = new DataSeries<DataPoint>(points, "Series Name");

        // Add to chart
        Chart.Series.Add(series);
    }

    public XyzChart Chart { get; }
}
```

### View Pattern

All views follow a consistent AXAML structure:

```xml
<UserControl>
    <Grid RowDefinitions="Auto,*">
        <!-- Header with title and description -->
        <Border Grid.Row="0">
            <StackPanel>
                <TextBlock Text="Title" />
                <TextBlock Text="Description" />
            </StackPanel>
        </Border>

        <!-- Chart display area -->
        <Border Grid.Row="1">
            <controls:SkiaChartView Chart="{Binding Chart}" />
        </Border>
    </Grid>
</UserControl>
```

### Data Handling

**Type Safety:**
- Used `IDataSeries<IDataPoint>` for series that need styling
- Used `List<IDataPoint>` instead of `List<DataPoint>` for compatibility
- Proper casting to avoid covariance issues with struct types

**Sample Data:**
- Seeded Random instances for reproducible data
- Realistic value ranges for each chart type
- Descriptive series names
