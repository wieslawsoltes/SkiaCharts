```csharp
public class ReactiveChartViewModel : ReactiveObject
{
    // Observable properties using RaiseAndSetIfChanged
    public string Title
    {
        get => _title;
        set => this.RaiseAndSetIfChanged(ref _title, value);
    }

    // Reactive subscriptions
    public ReactiveChartViewModel()
    {
        this.WhenAnyValue(x => x.Title, x => x.Subtitle)
            .Subscribe(_ => OnTitleChanged());
    }
}
```

### 3. Data Binding for Series ✅

Full series binding with `ObservableCollection`:

```csharp
public class ReactiveLineChartViewModel : ReactiveChartViewModel
{
    private ObservableCollection<DataSeries<IDataPoint>> _series = new();

    public ObservableCollection<DataSeries<IDataPoint>> Series
    {
        get => _series;
        set => this.RaiseAndSetIfChanged(ref _series, value);
    }

    public void AddSeries(string name, IEnumerable<IDataPoint> points)
    {
        var series = new DataSeries<IDataPoint>(points, name);
        Series.Add(series);
    }
}
```

### 4. Data Binding for Axes ✅

```csharp
public string XAxisLabel
{
    get => _xAxisLabel;
    set
    {
        if (SetProperty(ref _xAxisLabel, value) && Chart != null)
        {
            Chart.XAxis.Title = value;
            Refresh();
        }
    }
}
```

## Architecture Highlights

### 1. Dual ViewModel Approach
**ChartViewModelBase** - Simple INotifyPropertyChanged
- For basic MVVM scenarios
- Minimal dependencies
- Easy to understand

**ReactiveChartViewModel** - Full ReactiveUI
- For advanced scenarios
- Reactive property chains
- Command error handling
- WhenAnyValue subscriptions

### 2. Command Pattern
```
User Action → Command Execution → Async Operation → Update Properties → UI Refresh
```

### 3. Data Binding Flow
```
ViewModel Property Change
    ↓
INotifyPropertyChanged / ReactiveObject
    ↓
Avalonia Binding System
    ↓
Control Property Update
    ↓
Render Invalidation
    ↓
Chart Re-render
```

### 4. Converter Pipeline
```
XAML Value → Converter.Convert() → Target Property
Target Property → Converter.ConvertBack() → XAML Value
```

## Best Practices Implemented

1. **Property Change Notifications**
   - Always use SetProperty or RaiseAndSetIfChanged
   - Never bypass notification mechanisms
   - Use CallerMemberName for automatic names

2. **Command Design**
   - Async commands for long operations
   - Error handling via ThrownExceptions
   - Can Execute conditions via observables

3. **ObservableCollection Usage**
   - CollectionChanged for automatic updates
   - Proper add/remove operations
   - Chart synchronization on changes

4. **Memory Management**
   - Dispose of subscriptions
   - Weak event patterns
   - Timer disposal

5. **Testing**
   - Test ViewModels independently
   - Mock data for unit tests
   - Verify property notifications

## Usage Example

```csharp
// ViewModel
public class MainViewModel : ReactiveLineChartViewModel
{
    public MainViewModel()
    {
        Title = "Sales Dashboard";
        ChartTheme = ThemePresets.Professional;

        this.WhenAnyValue(x => x.ShowLegend)
            .Subscribe(_ => RefreshCommand.Execute().Subscribe());

        LoadSampleData();
    }

    private void LoadSampleData()
    {
        var points = new IDataPoint[]
        {
            new DataPoint(1, 100),
            new DataPoint(2, 150),
            new DataPoint(3, 120)
        };
        AddSeries("Q1 2025", points);
    }
}

// XAML
<charts:SkiaChartView
    Chart="{Binding Chart}"
    Title="{Binding Title}"
    ShowLegend="{Binding ShowLegend}"
    Width="800"
    Height="600" />

<CheckBox Content="Show Legend" IsChecked="{Binding ShowLegend}" />
<Button Content="Refresh" Command="{Binding RefreshCommand}" />
```
