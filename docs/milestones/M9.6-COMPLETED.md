## Architecture

### OHLC Data Point Structure

All financial charts use the `OhlcDataPoint` struct:

```csharp
public readonly struct OhlcDataPoint : IDataPoint
{
    public OhlcDataPoint(double x, double open, double high, double low, double close, double volume = 0)

    public double X { get; }          // Time/Period
    public double Y => Close;         // Y defaults to Close price
    public double Open { get; }       // Opening price
    public double High { get; }       // Highest price
    public double Low { get; }        // Lowest price
    public double Close { get; }      // Closing price
    public double Volume { get; }     // Trading volume
    public bool IsBullish => Close >= Open;  // Helper property
}
```

### Candlestick Chart Configuration

**CandlestickSeriesStyle Properties:**
- `CandleType`: Candlestick or OhlcBar
- `BullishColor`: Color for up moves
- `BearishColor`: Color for down moves
- `UseHollowCandles`: Hollow for bullish, filled for bearish
- `WickWidth`: Width of high-low lines
- `BodyBorderWidth`: Border width for hollow candles
- `CandleWidthRatio`: Candle width (0-1)
- `OhlcTickRatio`: Tick width for OHLC bars (0-1)

**CandlestickChartConfiguration Properties:**
- `ShowVolume`: Display volume bars below
- `VolumePanelRatio`: Volume panel height (0-1)
- `VolumeUpColor`: Volume bar color for up days
- `VolumeDownColor`: Volume bar color for down days
- `ShowHighLowLabels`: Display H/L labels
- `HighLowLabelFontSize`: Label font size
- `HighLowLabelColor`: Label color
