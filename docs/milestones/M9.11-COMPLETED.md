**Search Implementation:**
```csharp
private void FilterDemos()
{
    FilteredDemos.Clear();

    IEnumerable<DemoPage> demos;

    // Filter by category first
    if (SelectedCategory != null)
    {
        demos = SelectedCategory.Demos;
    }
    else
    {
        demos = DemoCatalog.AllDemos;
    }

    // Then filter by search query
    if (!string.IsNullOrWhiteSpace(SearchQuery))
    {
        var query = SearchQuery.ToLowerInvariant();
        demos = demos.Where(d =>
            d.Title.ToLowerInvariant().Contains(query) ||
            d.Description.ToLowerInvariant().Contains(query) ||
            d.Tags.Any(tag => tag.ToLowerInvariant().Contains(query)));
    }

    foreach (var demo in demos)
    {
        FilteredDemos.Add(demo);
    }
}
```

**UI Integration:**

### State Management

**View States:**
- Home (no category, no demo)
- Category View (category selected, no demo)
- Demo Detail (demo selected)
- Search Results (search active)

**Conditional Rendering:**
```xml
<!-- Welcome visible only on home -->
IsVisible="{Binding SelectedCategory, Converter={x:Static ObjectConverters.IsNull}}"

<!-- Demo list visible when no demo selected -->
IsVisible="{Binding SelectedDemo, Converter={x:Static ObjectConverters.IsNull}}"

<!-- Demo detail visible when demo selected -->
IsVisible="{Binding SelectedDemo, Converter={x:Static ObjectConverters.IsNotNull}}"
```

### Data Binding Pattern

**Reactive Properties:**
- `SearchQuery` → Triggers `FilterDemos()`
- `SelectedCategory` → Triggers `FilterDemos()`
- `SelectedDemo` → Updates from NavigationService
- `FilteredDemos` → ObservableCollection updates UI

**Commands:**
- `NavigateToHomeCommand` → Clears selections
- `NavigateToDemoCommand` → Navigates to demo
- `SelectCategoryCommand` → Filters by category
- `ToggleSidebarCommand` → Toggles sidebar
- `SearchCommand` → Performs search
