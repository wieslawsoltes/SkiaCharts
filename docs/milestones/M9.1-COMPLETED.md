## Architecture Highlights

### 1. Navigation Pattern
```
User Action
    ↓
Command Execution (ReactiveCommand)
    ↓
NavigationService.NavigateToDemo()
    ↓
CurrentDemo Property Updated
    ↓
View Model Instantiated
    ↓
UI Updates via Data Binding
    ↓
ContentControl Displays View Model
```

### 2. Search & Filter Flow
```
SearchQuery Changed
    ↓
FilterDemos() Called
    ↓
Apply Category Filter
    ↓
Apply Search Query Filter
    ↓
Update FilteredDemos Collection
    ↓
ObservableCollection Notifies UI
    ↓
Demo Grid Refreshes
```

### 3. MVVM Data Flow
```
MainWindowViewModel
    ├── Categories (from DemoCatalog)
    ├── FilteredDemos (ObservableCollection)
    ├── SelectedCategory (for filtering)
    ├── SelectedDemo (for navigation)
    └── NavigationService
            └── CurrentViewModel (for display)
```
