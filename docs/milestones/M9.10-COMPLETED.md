        double y = baseValue + Math.Sin(i * 0.4 + s) * 10 + random.Next(-3, 4);

## Error Resolution

### Error 1: LineChart MarkerColor Property

**Initial Error:**
```
error CS0117: 'LineChart' does not contain a definition for 'MarkerColor'
```

**Cause:** Used non-existent MarkerColor property

**Fix:** Removed MarkerColor property:
```csharp
// Before:
LineColor = new SKColor(255, 87, 34),
MarkerColor = new SKColor(255, 152, 0)

// After:
LineColor = new SKColor(255, 87, 34)
```

### Error 2: BarChartConfiguration Properties

**Initial Error:**
```
error CS0117: 'BarChartConfiguration' does not contain a definition for 'BarSpacing'
```

**Cause:** Used non-existent BarSpacing and GroupSpacing properties

**Fix:** Used correct BarChartConfiguration properties:
```csharp
// Before:
Configuration = new BarChartConfiguration
{
    BarSpacing = 0.3,
    GroupSpacing = 0.5
}

// After:
Configuration = new BarChartConfiguration
{
    Orientation = BarOrientation.Horizontal,
    StackMode = BarStackMode.None
}
```
