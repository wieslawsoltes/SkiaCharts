## Architecture

### View Model Pattern

All view models follow consistent patterns:

**Performance Pattern (Many Series):**
```csharp
public class ManySeriesViewModel : ReactiveObject
{
    public ManySeriesViewModel()
    {
        Chart = new LineChart { /* config */ };

        // Generate 100 series
        for (int seriesIndex = 0; seriesIndex < 100; seriesIndex++)
        {
            var series = GenerateSeries(seriesIndex);
            Chart.Series.Add(series);
        }
    }

    public LineChart Chart { get; }
}
```

**Mixed Types Pattern:**
```csharp
public class MixedTypesViewModel : ReactiveObject
{
    public LineChart LineChart { get; }
    public BarChart BarChart { get; }
    public AreaChart AreaChart { get; }

    // Constructor initializes all three charts
}
```

**Stacked Pattern:**
```csharp
public class StackedAreaViewModel : ReactiveObject

    }

```

### Configuration Pattern

Charts use Configuration and DefaultStyle properties:

**Area Chart:**
```csharp
new AreaChart
{
    Configuration = new AreaChartConfiguration
    {
        StackMode = AreaStackMode.Stacked // or None
    },
    DefaultStyle = new AreaSeriesStyle
    {
        LineWidth = 2f,
        ShowLine = true,
        FillAlpha = 100
    }
}
```

**Bar Chart:**
```csharp
new BarChart
{
    Configuration = new BarChartConfiguration
    {
        Orientation = BarOrientation.Vertical,
        StackMode = BarStackMode.None
    },
    DefaultStyle = new BarSeriesStyle
    {
        BarWidthRatio = 0.7,
        CornerRadius = 4f
    }
}
```

### Type Covariance Handling

Used `IDataSeries<IDataPoint>` for return types to handle struct covariance:

```csharp
private IDataSeries<IDataPoint> CreateSeries(string name, SKColor color, int offset)
{
    var points = new List<IDataPoint>();  // Interface type
    // ... populate points ...
    return new DataSeries<IDataPoint>(points, name);
}
```

## Error Resolution

### Error 1: Missing Styling Namespace
- **Error:** `CS0234: The type or namespace name 'Styling' does not exist`
- **Cause:** Incorrect using statement `SkiaCharts.Core.Styling`
- **Fix:** Removed unnecessary using statement, types are in `SkiaCharts.Core.Charts`

### Error 2: Direct Property Assignment
- **Error:** `CS0117: 'AreaChart' does not contain a definition for 'Stacked'`
- **Cause:** Attempted direct property assignment instead of Configuration
- **Fix:** Used `Configuration = new AreaChartConfiguration { StackMode = ... }`

### Error 3: Type Covariance
- **Error:** `CS1503: cannot convert from DataSeries<DataPoint> to IDataSeries<IDataPoint>`
- **Cause:** DataPoint is a struct, doesn't support covariance
- **Fix:** Changed return types to `IDataSeries<IDataPoint>` and used `List<IDataPoint>`
