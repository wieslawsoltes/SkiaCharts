## Architecture Highlights

### 1. Theme Application Flow
```
User Request
    ↓
ChartThemeManager.ApplyTheme()
    ↓
Remove old theme class
    ↓
Add new theme class
    ↓
Set ChartTheme property
    ↓
AXAML style selectors match
    ↓
Properties updated via setters
    ↓
Control re-renders
```

### 2. Resource Resolution
```
Control Property Request
    ↓
{DynamicResource ChartBackgroundBrush}
    ↓
Search in Styles.Resources
    ↓
Search in MergedDictionaries
    ↓
Find in ChartResources.axaml
    ↓
Apply color/value to control
```

### 3. Attached Property System
```xml
<SkiaChartView theming:ChartTheme.ThemeVariant="Dark">
    ↓
ChartTheme.ThemeVariantProperty changed
    ↓
OnThemeVariantChanged handler
    ↓
ChartThemeManager.ApplyTheme()
    ↓
Update control classes
    ↓
Set ChartTheme property
```

### 4. Auto-Sync Flow
```
User enables AutoSyncTheme
    ↓
Subscribe to ActualThemeVariant changes
    ↓
Avalonia theme changes
    ↓
PropertyChanged event fires
    ↓
ChartThemeManager.SyncWithAvaloniaTheme()
    ↓
Apply matching theme variant
```

## Usage Examples

### 1. Basic Theme Application (C#)
```csharp
var chartView = new SkiaChartView();
ChartThemeManager.ApplyTheme(chartView, ChartThemeVariant.Dark);
```

### 2. Theme Toggle Button
```csharp
private ChartThemeVariant _currentTheme = ChartThemeVariant.Light;

private void OnToggleTheme()
{
    _currentTheme = ChartThemeManager.ToggleTheme(_currentTheme);
    ChartThemeManager.ApplyTheme(ChartView, _currentTheme);
}
```

### 3. XAML Attached Property
```xml
<Window xmlns:theming="using:SkiaCharts.Avalonia.Theming"
        xmlns:charts="using:SkiaCharts.Avalonia.Controls">
    <charts:SkiaChartView
        theming:ChartTheme.ThemeVariant="Professional"
        Width="800" Height="600" />
</Window>
```

### 4. Auto-Sync with Avalonia Theme
```xml
<charts:SkiaChartView
    theming:ChartTheme.AutoSyncTheme="True"
```

### 5. System Theme Detection
```csharp
// Detect and apply system theme
var systemTheme = ChartThemeManager.DetectSystemTheme();

```

### 6. Theme ComboBox
```csharp
// In ViewModel
public Array ThemeVariants => Enum.GetValues(typeof(ChartThemeVariant));

private ChartThemeVariant _selectedTheme;
public ChartThemeVariant SelectedTheme
{
    get => _selectedTheme;
    set
    {
        _selectedTheme = value;
        ChartThemeManager.ApplyTheme(ChartView, value);
```


## Integration with Milestone 8.3 (MVVM)

The theming system integrates seamlessly with MVVM:

```csharp
public class ChartViewModel : ReactiveChartViewModel
{
    private ChartThemeVariant _themeVariant = ChartThemeVariant.Light;

    public ChartThemeVariant ThemeVariant
    {
        get => _themeVariant;
        set
        {
            this.RaiseAndSetIfChanged(ref _themeVariant, value);
            ChartTheme = ChartThemeManager.GetChartTheme(value);
        }
    }

    public ReactiveCommand<ChartThemeVariant, Unit> ChangeThemeCommand { get; }

    public ChartViewModel()
    {
        ChangeThemeCommand = ReactiveCommand.Create<ChartThemeVariant>(theme =>
        {
            ThemeVariant = theme;
        });
    }
}
```

```xml
<charts:SkiaChartView Chart="{Binding Chart}"
                      ChartTheme="{Binding ChartTheme}" />

<ComboBox ItemsSource="{Binding ThemeVariants}"
          SelectedItem="{Binding ThemeVariant}" />
```
