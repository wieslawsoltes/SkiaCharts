```csharp
private void UpdateData()
{
    // Add new point
    _currentValue += (_random.NextDouble() - 0.5) * 10;
    _currentValue = Math.Clamp(_currentValue, 0, 100);
    _dataPoints.Add(new DataPoint(_currentX++, _currentValue));

    // Remove old points
    if (_dataPoints.Count > MaxDataPoints)
    {
        _dataPoints.RemoveAt(0);
    }

    // Update series
    Chart.Series.Clear();
    var series = new DataSeries<IDataPoint>(_dataPoints, "Real-Time Data");
    Chart.Series.Add(series);

    this.RaisePropertyChanged(nameof(Chart));
}
```

**Status Display:**
```csharp
private void UpdatePrice()
{
    double change = (_random.NextDouble() - 0.5) * 3;
    _currentPrice += change;
    _currentPrice = Math.Max(90, Math.Min(110, _currentPrice));

    // Update status with direction
    string direction = change > 0 ? "▲" : change < 0 ? "▼" : "━";
    Status = $"${_currentPrice:F2} {direction} {(change >= 0 ? "+" : "")}{change:F2}";
}
```

## Architecture

### ReactiveUI Observable Pattern

Both demos use ReactiveUI's `Observable.Interval` for timed updates:

```csharp
Observable
    .Interval(TimeSpan.FromMilliseconds(interval))
    .ObserveOn(RxApp.MainThreadScheduler)  // Ensure UI thread
    .Subscribe(_ => UpdateMethod());
```

### IDisposable Implementation

Proper resource cleanup:

```csharp
public class StreamingViewModel : ReactiveObject, IDisposable
{
    private readonly IDisposable _updateSubscription;

    public void Dispose()
    {
        _updateSubscription?.Dispose();
    }
}
```

### Chart Update Pattern

**Series Recreation:**
```csharp
Chart.Series.Clear();
var series = new DataSeries<IDataPoint>(points, "Series Name");
```

**FIFO Queue Pattern:**

All updates use `ObserveOn(RxApp.MainThreadScheduler)` to ensure thread safety.
