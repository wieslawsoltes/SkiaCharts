## Architecture Highlights

### Interactive Elements Flow
```
User Input → Input Router
    ↓
Hit Testing → Identify Target
    ↓
Interactive Managers (Tooltip, Selection, Hover, etc.)
    ↓
Render/Update → Visual Feedback
    ↓
Events → Application Logic
```

### Manager Integration Pattern
```
Chart → Manages Multiple Managers
    ├── TooltipManager
    ├── CrosshairManager
    ├── SelectionManager
    ├── ContextMenuManager
    └── HoverHighlightManager
```

### Event-Driven Architecture
All managers use event-driven patterns:
- `TooltipChanged` event
- `PositionChanged` event (crosshair)
- `SelectionChanged` event
- `MenuRequested` / `ItemSelected` events
- `HoverChanged` event

## Technical Specifications

### Performance Characteristics
- **Tooltip Update**: O(1) - Direct state update
- **Selection Operations**: O(1) average (HashSet)
- **Hover Detection**: O(1) - Reference equality
- **Crosshair Update**: O(n) for synchronized (n = number of crosshairs)
- **Range Hit Test**: O(1) - Geometric calculation

### Memory Footprint
- TooltipManager: ~200 bytes (state + renderer reference)
- CrosshairManager: ~150 bytes
- SelectionManager: ~base + O(n) for n selected items
- ContextMenuManager: ~base + O(m) for m menu items
- HoverHighlightManager: ~180 bytes
- Total per chart with all managers: ~800 bytes + selection/menu items

### Thread Safety
- Not thread-safe by design (UI thread only)
- Event handlers execute synchronously
- No internal locking required

## Design Patterns Used

✅ **Manager Pattern**: Each interactive feature has a dedicated manager
✅ **Strategy Pattern**: Pluggable renderers (tooltip, highlight styles)
✅ **Observer Pattern**: Event-based notifications
✅ **Command Pattern**: Context menu actions
✅ **State Pattern**: Hover/selection state management
✅ **Template Method**: Custom renderers extend base behavior

## Usage Examples

### Tooltip Setup
```csharp
var tooltipManager = new TooltipManager
{
    ShowDelay = TimeSpan.FromMilliseconds(300),
    Renderer = new DefaultTooltipRenderer
    {
        BackgroundColor = new SKColor(20, 20, 20, 240),
        TextColor = SKColors.White,
        CornerRadius = 6
    }
};

// On mouse move/hover
tooltipManager.Update(dataPoint, mousePosition);

// In render loop
tooltipManager.Render(canvas, chartBounds);
```

### Crosshair Setup
```csharp
var crosshair = new CrosshairManager
{
    LineStyle = CrosshairLineStyle.Dashed,
    LineColor = new SKColor(200, 200, 200, 180),
    ShowLabels = true
};

// On mouse move
crosshair.Update(mousePosition, viewport);

// In render loop
crosshair.Render(canvas, chartBounds, viewport);
```

### Selection Setup
```csharp
var selection = new SelectionManager
{
    SelectionMode = SelectionMode.Multiple
};

selection.SelectionChanged += (s, e) =>
{
    Console.WriteLine($"Selected: {e.SelectedItems.Count} items");
};

// On click
if (hitTestResult != null)
{
    bool ctrlPressed = modifiers.HasFlag(KeyModifiers.Control);
    selection.Select(hitTestResult, addToSelection: ctrlPressed);
}
```

### Context Menu Setup
```csharp
var contextMenu = new ContextMenuManager();

contextMenu.MenuRequested += (s, e) =>
{
    if (e.Target is DataPoint dataPoint)
    {
        e.Items.Add(new ContextMenuItem
        {
            Text = $"Value: {dataPoint.Y:F2}",
            IsEnabled = false
        });
        e.Items.Add(ContextMenuItem.Separator());
        e.Items.Add(new ContextMenuItem
        {
            Text = "Copy Value",
            Action = () => Clipboard.SetText(dataPoint.Y.ToString())
        });
    }
};

// On right-click
contextMenu.RequestMenu(clickPosition, hitTestResult);
```

### Hover Highlighting Setup
```csharp
var hoverManager = new HoverHighlightManager
{
    HighlightStyle = HighlightStyle.Glow,
    HighlightColor = new SKColor(255, 200, 0, 150),
    HighlightDelay = TimeSpan.FromMilliseconds(50)
};

// On mouse move
hoverManager.Update(hitTestResult, mousePosition);

// In render loop (for each data point)
if (hoverManager.IsHovered(dataPoint))
{
    hoverManager.RenderCircleHighlight(canvas, pointPosition, radius);
}
```
